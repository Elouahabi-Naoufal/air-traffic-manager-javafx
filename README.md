## About The Project

This repository is a **planning scaffold**. It currently contains a single `.gitkeep` file and no
source code, build file, tests or application.

The intent recorded in the repository description is to rebuild the air-traffic-manager simulation
on a modern JavaFX foundation. No implementation details have been committed, so this README does
not claim any features, architecture or commands beyond that.

The existing simulation lives in [AirTrafficManager](https://github.com/Elouahabi-Naoufal/AirTrafficManager),
which uses a Swing window over a MongoDB-backed simulation.

<!-- GETTING STARTED -->
## Getting Started

### Prerequisites

There is nothing to build or run yet. A future implementation will need a JDK and the JavaFX SDK
(or a build tool that resolves JavaFX dependencies).

### Installation

1. Clone the repository
   ```sh
   git clone https://github.com/Elouahabi-Naoufal/air-traffic-manager-javafx.git
   cd air-traffic-manager-javafx
   ```
2. There are no dependencies to install and no build step to run.

<p align="right">(<a href="#readme-top">back to top</a>)</p>

<!-- USAGE -->
## Usage

This repository is empty, so there is no application to launch. Use
[AirTrafficManager](https://github.com/Elouahabi-Naoufal/AirTrafficManager) for the current,
working simulation.
